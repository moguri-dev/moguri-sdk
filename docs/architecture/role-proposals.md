## Original model evidence, not acceptance

Resolve only a completed independently retained owned-role input with the
exact final recorded draft/revision/escalation step, successful known bounded
accounting and its original normalized tool-less result. A critic/router is
not a code proposer, and partial/stopped/failed work cannot become a completed
proposal. Parse only exact bounded patch JSON against the original selected
paths and bases. Do not repair, truncate, infer new files or relabel imports.

Read-only SDK/CLI/TUI/desktop inspection must work after source retention
without a live root, provider, credentials, inference or write. The captured
origin binds sequence input, role input/result, actual step/model/provider/API,
role index and retained source event. This says where bytes came from, not
that the model family is independent, code is correct or the user accepted it.

## Exact reviewed publication

Loading fills the local proposal editor only. Staging preview includes the
canonical role origin in its document/digest, together with original roots,
bases and exact bytes. Stage rechecks the actual retained proposal and current
source policy; omitted, swapped, deleted or edited origin cannot acquire
verified model attribution. Existing fixed-model generation origin remains
compatible and mutually exclusive.

Candidate document/record retain an immutable self-contained origin snapshot
and canonical model source. The three original sequence input, role input and
raw-result blobs gain the candidate's independent grant before effects.
Version-5 candidate exports include them; earlier formats retain their versions.
The exact staging preview discloses this separate retention in every client.
A later deletion of the source role report does not erase this separately
retained copy or refund its calls. A staged candidate
still needs a separate fresh source review and actual-user acceptance. No
automatic source write, commit, push or branch action.

Both clients preserve dirty edits and current profile/session/env/workspace/
mode/revision scope during asynchronous reads. Editing the loaded summary,
file bytes or staging root clears verified origin. An incompatible scope can
inspect retained data but cannot silently load it into another checkout.

never delete state to upgrade. Copies survive independently and recovery never
