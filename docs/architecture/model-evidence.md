# Explicit provider-declared model evidence

Source 0.28/protocol 34 implements this development contract. Full source,
independently installed archive and exact native qualification are still
pending. Qualified 0.27/protocol 33 and its immutable SDK/native delivery remain
preserved. Sandbox and personal inference stay off.

The maintained pi-ai 1.3 Copilot adapter filters static supported models using
account `availableModelIds`. Its OAuth catalogue parser retains picker/policy
IDs, not raw family/vendor/version metadata, and its auth context exposes no
fetch interception hook. Do not infer independence from model names, aliases,
the `github-copilot` provider ID or generated family fixtures.

Public catalogue parsing in [this maintained client source](https://github.com/anomalyco/opencode/blob/3260ec767ca9d18a2424231e04f7a756186dc011/packages/core/src/github-copilot/models.ts)
corroborates explicit `capabilities.family` and `version` fields. These are
provider declarations, not attested weights, independent training, quality,
permission or a user answer. Optional raw vendor data has the same limitation.
No implementation is copied or forked from that client.

## Boundary

Use an explicit read-only SDK/CLI/TUI/desktop inspection action. Ordinary
Copilot login, discovery and inference remain unchanged; no background metadata
requests, automatic family cache, pool widening or compound enablement.
The user was unavailable for the fetch-timing choice, so the conservative
explicit-inspection option was selected.

Reuse Node fetch/crypto, TypeBox and maintained pi-ai (MIT), the existing scoped
secret backend and immutable profile client. Only the exact current available
Copilot model may be inspected. Use its existing short-lived request access and
validated account-specific HTTPS Copilot catalogue endpoint, never an ambient
token, default account, model-selected URL, redirect or arbitrary hostname.
No prompt, repository content, microphone, weights or inference request.
Local/Remote endpoint families remain unknown without an actual supported
evidence contract; do not manufacture them from prefixes.

Bound request/body/model counts, total deadline and lossless string sizes.
Reject duplicate/missing exact IDs, malformed fields, credential echoes,
unexpected resources and stale account epochs. Cancellation, logout and
shutdown must abort owned reads and cannot publish an old-account report.
Unknown family stays explicitly unknown, never an independent-critic grant.
Return only allowlisted declarations, source/field, observation time, digest
and clear caveats; never retain a whole provider response or bearer credential.
Inspection creates no model call, charge, approval or durable model answer.

## Schema, clients and gates

A versioned browser-safe evidence report and explicit query use
protocol/database 34 with an additive compatibility marker, not rewritten
events or a second store. Existing schema-33 role-origin data, raw-copy grants,
ciphertext and receipts remain unchanged; failed marker must reopen exactly.
Reports are read-only ephemeral results, not automatic durable memory or
instructions. Future routing may capture them in its immutable policy input
only after separate eligibility/quality/authority checks.

All clients use the same SDK read. Model/scope changes discard stale UI data;
errors remain visible without breaking fixed-model login or dropping drafts.
Generated real-adapter/HTTP tests must cover no implicit reads during login,
exact headers/resource, absent versus declared fields, ambiguity, Unicode,
size/deadline/cancel/logout races, secret echoes and unknown/local/foreign
models, plus raw migration rollback and packed-consumer/browser safety.
No public compound/finite-kupo/Max readiness follows from this metadata alone.

The digest is lowercase SHA-256 of the UTF-8 prefix
`moguri-model-evidence-v1` plus one NUL byte, then the compact `JSON.stringify`
of the report without `digest`, in the producer's field order. Observation time
and warning participate. It is a content digest, not a signature, JCS encoding
or training attestation. Claims preserve declared text rather than normalizing
or manufacturing a family.

The built/installed qualifier runs a private child against the actual package
default adapter, without injecting a substitute ProviderAdapter. Node's
test-process module hook replaces only `@napi-rs/keyring` with a generated
in-memory implementation restricted to the exact Default provider namespace.
Catalogue fetch is intercepted; only the owned service loopback may use real
networking. This does not open an OS keychain, log in a person, make paid
inference or qualify live Copilot entitlement/header compatibility.
The same helper is wired into packed-consumer and actual native qualification;
those delivered-byte gates are pending.
